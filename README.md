# تەنها دەنگ (YtAudio)

ئەپێکی ئەندرۆید کە لینکی یوتیوب وەردەگرێت و تەنها دەنگەکەی لێدەدات.
لە ئەپی یوتیوب: «هاوبەشکردن» (Share) ← «تەنها دەنگ».

## دروستکردنی APK بە GitHub

1. ناوەڕۆکی ئەم بوخچەیە بخەرە ناو ڕیپۆزیتۆرییەکی GitHub
   (بوخچەی `.github` بە خاڵەوە).
2. بڕۆ بۆ بەشی **Actions** و چاوەڕێ بکە تا نیشانەی سەوز دەردەکەوێت (٣ تا ٥ خولەک).
3. کرتە لەسەر ڕیزەکە بکە و لە بەشی **Artifacts** فایلی `YtAudio-apk` دابگرە.
4. `app-debug.apk` بخەرە سەر مۆبایلەکەت و دایبمەزرێنە.

## لێدان کاتێک شاشە داخراوە

جاری یەکەم ئەپەکە دەپرسێت کە لە «باشترکردنی پاتری» دەرچێت؛ ڕێگە بدە.
لە مۆبایلەکانی شیاومی، هواوی و سامسۆنگ، لە ڕێکخستنەکانی ئەپەکەدا «Autostart» یان «بێ سنووری پاتری» چالاک بکە.
